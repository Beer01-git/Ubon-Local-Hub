WEB APPLICATION PROTOTYPE (INTERACTIVE FRONTEND)

โปรเจกต์พัฒนาเว็บแอปพลิเคชันเพื่อโปรโมตสินค้าชุมชนและ OTOP ของจังหวัดอุบลราชธานี ออกแบบในสไตล์ Minimalist เน้นใช้งานง่าย และจำลองการจัดการข้อมูลแบบกึ่ง Dynamic จัดทำขึ้นเพื่อการเรียนรู้และพัฒนาทักษะในการพัฒนาเว็บไซต์

1

แนวคิดของโปรเจกต์

สินค้า OTOP และของดีประจำอำเภอต่างๆ ในจังหวัดอุบลราชธานี มีความหลากหลายแต่ยังขาดศูนย์กลางในการเข้าถึงข้อมูล Ubon Local Hub จึงถูกพัฒนาขึ้นเพื่อ:

สำหรับผู้ใช้ทั่วไป / นักท่องเที่ยว

ค้นหา กรอง และดูรายละเอียดสินค้า OTOP แยกตามอำเภอและหมวดหมู่ได้อย่างสะดวก เชื่อมต่อกับช่างฝีมือและผู้ผลิตโดยตรง

สำหรับร้านค้าชุมชน (จำลองระบบ)

มีหน้า Merchant Dashboard สำหรับจัดการคลังสินค้า (เพิ่ม / แก้ไข / ลบ) พร้อมสถิติสรุปแบบ Real-time

2

ฟีเจอร์หลักในระบบ

หน้าหลัก (index.html)

  • ช่องค้นหาสินค้า: พิมพ์ค้นหาชื่อสินค้า ชื่อร้าน หรืออำเภอแบบ Real-time
  • ระบบ Filter สองชั้น: กรองตามอำเภอ (5 อำเภอ) และหมวดหมู่สินค้า (6 หมวด) พร้อมกัน
  • แถบ Filter Tag: แสดง Tag ตัวกรองที่กำลังใช้งาน พร้อมปุ่มรีเซ็ตทั้งหมด
  • Product Grid: แสดงการ์ดสินค้าพร้อมรูปภาพ, ราคา, OTOP Badge, ชื่อร้าน และอำเภอ
  • Product Detail Modal: คลิกดูรายละเอียดเต็ม พร้อมข้อมูลติดต่อ (โทรศัพท์, LINE, ที่อยู่) และปุ่มคัดลอก
  • ปุ่มรีเซ็ตข้อมูลตัวอย่าง: รีเซ็ตข้อมูลสินค้ากลับเป็นค่าเริ่มต้นได้อย่างรวดเร็ว

หน้าจัดการร้านค้า (dashboard.html)

  • สถิติสรุป: แสดงจำนวนสินค้า, มูลค่ารวมในระบบ และจำนวนอำเภอที่ครอบคลุม
  • เพิ่มสินค้าใหม่: ฟอร์มกรอกข้อมูลสินค้าครบถ้วน พร้อมระบบพรีวิวรูปภาพก่อนบันทึก
  • แก้ไขสินค้า: จัดการแก้ไขข้อมูลสินค้าผ่าน Modal Form
  • ลบสินค้า: ระบบยืนยันผ่าน Confirmation Modal ป้องกันการกดลบพลาด
  • บันทึกใน localStorage: ข้อมูลที่จัดการจะถูกบันทึกไว้ในเบราว์เซอร์อัตโนมัติ

หมายเหตุสำคัญ

  • โปรเจกต์นี้เป็น Frontend Prototype จัดทำขึ้นเพื่อการเรียนรู้และพัฒนาทักษะการสร้างเว็บแอปพลิเคชัน
  • ข้อมูลสินค้าจัดเก็บใน localStorage ของเบราว์เซอร์ หากล้างประวัติการท่องเว็บ ข้อมูลที่เพิ่มใหม่จะรีเซ็ต
  • ข้อมูลร้านค้า เบอร์โทรศัพท์ และช่องทางติดต่อเป็น ข้อมูลจำลองเพื่อการทดสอบ
