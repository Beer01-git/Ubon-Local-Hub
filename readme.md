#  Ubon Local Hub — ศูนย์รวมของดีและสินค้า OTOP เมืองอุบลฯ

> **Web Application Prototype (Interactive Frontend)**  
> โปรเจกต์พัฒนาเว็บแอปพลิเคชันเพื่อโปรโมตสินค้าชุมชนและ OTOP ของจังหวัดอุบลราชธานี ออกแบบในสไตล์ Minimalist เน้นใช้งานง่าย และจำลองการจัดการข้อมูลแบบกึ่ง Dynamic จัดทำขึ้นเพื่อการเรียนรู้และพัฒนาทักษะในการพัฒนาเว็บไซต์

---

##  แนวคิดของโปรเจกต์

สินค้า OTOP และของดีประจำอำเภอต่างๆ ในจังหวัดอุบลราชธานี มีความหลากหลายแต่ยังขาดศูนย์กลางในการเข้าถึงข้อมูล **Ubon Local Hub** จึงถูกพัฒนาขึ้นเพื่อ:

1. **สำหรับผู้ใช้ทั่วไป / นักท่องเที่ยว** — ค้นหา กรอง และดูรายละเอียดสินค้า OTOP แยกตามอำเภอและหมวดหมู่ได้อย่างสะดวก
2. **สำหรับร้านค้าชุมชน (จำลองระบบ)** — มีหน้า Dashboard สำหรับจัดการคลังสินค้า (เพิ่ม / แก้ไข / ลบ) พร้อมสถิติสรุป

---

##  ฟีเจอร์หลัก

### หน้าหลัก (index.html)
-  **ช่องค้นหาสินค้า** — พิมพ์ชื่อสินค้าหรือชื่อร้านเพื่อค้นหาแบบ Real-time
-  **ระบบ Filter สองชั้น** — กรองตามอำเภอ (6 อำเภอ) และหมวดหมู่สินค้า (6 หมวด) พร้อมกัน
-  **แถบ Filter Tag** — แสดง Tag ที่เลือกอยู่ พร้อมปุ่มรีเซ็ตทั้งหมด
-  **Product Grid** — แสดงการ์ดสินค้าพร้อมรูปภาพ, ราคา, ดาว OTOP, ชื่อร้าน และอำเภอ
-  **Product Detail Modal** — คลิกการ์ดเพื่อดูรายละเอียดเต็ม พร้อมข้อมูลติดต่อ (โทรศัพท์, Line, ที่อยู่) และปุ่มคัดลอก
-  **ปุ่มรีเซ็ตข้อมูลตัวอย่าง** — กดรีเซ็ตกลับเป็นข้อมูลเริ่มต้นได้

### หน้า Dashboard (dashboard.html)
-  **สถิติสรุป** — แสดงจำนวนสินค้า, มูลค่ารวม และจำนวนอำเภอที่ใช้งาน
-  **เพิ่มสินค้าใหม่** — ฟอร์มกรอกข้อมูลสินค้าครบถ้วน (ชื่อ, ราคา, อำเภอ, หมวดหมู่, ดาว OTOP, รายละเอียด, ข้อมูลติดต่อ, รูปภาพ)
-  **แก้ไขสินค้า** — กดแก้ไขจากตารางแล้วแก้ผ่าน Modal Form
-  **ลบสินค้า** — ลบพร้อม Confirmation Modal ป้องกันการลบพลาด
-  **ตารางสินค้า** — แสดงรายการสินค้าทั้งหมดในรูปแบบตาราง พร้อมปุ่มแก้ไข/ลบ
-  **เก็บข้อมูลใน localStorage** — ข้อมูลที่เพิ่มหรือแก้ไขจะถูกเก็บไว้ในเบราว์เซอร์ ไม่หายเมื่อรีเฟรช

### ระบบ Design
-  **Design System 60/30/10** — 60% Warm Canvas, 30% Sage/White Surface, 10% Emerald/Amber Accent
-  **Responsive Design** — รองรับทั้งคอมพิวเตอร์และมือถือ
-  **Toast Notification** — แจ้งเตือนเมื่อทำรายการสำเร็จ

##  เทคโนโลยีที่ใช้

| เทคโนโลยี | รายละเอียด |
|---|---|
| **HTML5** | โครงสร้างหน้าเว็บ ใช้ Semantic Elements |
| **JavaScript (ES6+)** | ตรรกะฝั่ง Client ทั้งหมด ไม่ใช้ Framework |
| **Tailwind CSS (CDN)** | จัดการ Layout และ Utility Classes |
| **Custom CSS** | Design Tokens, ปุ่ม, Animation และ Custom Components |
| **Google Fonts** | ฟอนต์ Prompt (ไทย) + Inter (ตัวเลข/อังกฤษ) |
| **localStorage** | จัดเก็บข้อมูลสินค้าในเบราว์เซอร์ |

##  ข้อมูลตัวอย่างในระบบ

### อำเภอที่รองรับ (5 อำเภอ + ตัวเลือก "ทุกอำเภอ")
| อำเภอ | ID |
|---|---|
| เมืองอุบลฯ | `ubon` |
| โขงเจียม | `khongjiam` |
| วารินชำราบ | `warin` |
| พิบูลมังสาหาร | `phibun` |
| สว่างวีระวงศ์ | `sawang` |

### หมวดหมู่สินค้า (6 หมวด + ตัวเลือก "ทั้งหมด")
ผ้าทอ/เครื่องแต่งกาย · อาหาร/ของกินพื้นถิ่น · งานจักสาน/หัตถกรรม · สมุนไพร/สุขภาพ · เครื่องประดับ/ของที่ระลึก · ของฝากทั่วไป

### สินค้าตัวอย่างเริ่มต้น (5 รายการ)
1. **ผ้าทอมือย้อมครามลายกาบบัว** — โขงเจียม (850 บาท) 
2. **น้ำพริกกะปิปลาแม่น้ำมูลสูตรโบราณ** — วารินชำราบ (85 บาท) 
3. **หมูยอพริกไทยดำเมืองอุบล** — เมืองอุบลฯ (180 บาท) 
4. **ซาลาเปาโบราณไส้หมูสับไข่เค็มแก่งสะพือ** — พิบูลมังสาหาร (120 บาท) 
5. **เครื่องจักสาน** — สว่างวีระวงศ์ (150 บาท)

##  หมายเหตุ

- โปรเจกต์นี้เป็น **Frontend Prototype** สำหรับการเรียนรู้ ไม่มี Backend หรือฐานข้อมูลจริง
- ข้อมูลสินค้าทั้งหมดเก็บใน **localStorage** ของเบราว์เซอร์ หากล้าง Browser Data ข้อมูลที่เพิ่มเข้าไปจะหายไป
- รูปภาพสินค้าตัวอย่างเก็บในโฟลเดอร์ `JPG/` หากไม่พบรูปจะแสดง Placeholder SVG แทน
- ข้อมูลติดต่อร้านค้าในระบบเป็น **ข้อมูลจำลอง** ไม่ใช่ข้อมูลจริง
